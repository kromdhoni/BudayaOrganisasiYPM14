# BudayaOrganisasiYPM

Template interaktif Mind Mapping Budaya Organisasi YPM — YouTube Style (sinematik).
Siap diunggah ke GitHub Pages.

## Cara pakai
1. Upload seluruh folder ke repository GitHub (public).
2. Aktifkan GitHub Pages (Settings → Pages → Source: main / root).
3. Buka URL GitHub Pages untuk melihat situs.

## Struktur
- index.html
- assets/
  - logo-ypm.png
  - music.wav
  - intro-bg.jpg
  - cover.jpg
